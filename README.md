# Mira & Luna — Celestial Inspired Jewellery

Production-ready static catalog website with admin panel.

## Setup
```
npm install
npm run dev
```

## Deploy to Netlify
1. Push to GitHub
2. Connect to Netlify
3. Enable Identity + Git Gateway for admin
4. Invite yourself as admin
5. Go to /admin

## Admin Login
- Username: your email (invited via Netlify Identity)
- Password: set during invitation
